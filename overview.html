Architecture · 10 layers · 4 rails

One task. Top to bottom. Ten layers, three are ours.

Every layer either narrows the task, evaluates it, or explains it. The three signal-orange layers (Taste · Voice · Memory) are where Atlas differs from generic agent stacks. Every input to the LLM plays one of three roles — descriptive, evaluative, or prescriptive.

01
Surface entry
Where the task arrives.
Dispatch mobile · Cowork · Claude Code CLI · launchd · Obsidian
02
Intent classify
Project detection + routing class. Bracket-prefix triggers state-load rule.
[project] prefix · task-router · slug detection
03
Context descriptive · what is
Obsidian README → canonical outputs → live external state. In that order. Failing this layer is what caused the Klaviyo Path A rebuild.
obsidian-vault · vince-agents-context · live BQ · live Klaviyo · live Xero
04
Orchestration
The loop. Plan → write → check → merge. Heavy work fans out to subagents.
Cowork agent loop · tmux-orchestrator MCP
05
Model
Route to the cheapest brain that meets the bar. Subscription lane by default; API only when subscription can't reach.
Opus 5 · Sonnet 5 · Haiku 4.5 · Kimi K3 · Ollama on Axis
06
Tools
~30 MCPs. Aspirationally per-project scoped; today every session loads all.
vince-agents-context · obsidian-vault · bigquery-rollie · klaviyo · notion · missive · higgsfield · +24 more
07
Runtime
Where work executes. Sandboxed. Network scoped. Financial actions read-only.
bash sandbox · Docker · SSH to Axis
08
Taste gate evaluative · is this worthy
Creative outputs pass through taste-gate + destination-gate before delivery. Brand refs, identity anchors, ceiling check.
taste-gate · destination-gate · Pinterest anchors · Rollie brand bible

Voice gate evaluative · 1st-person only
First-person Vince writing loads the Writing & Thinking Doctrine. Journey not conclusion. Grounded emotion. Discovery over persuasion.

Memory / provenance prescriptive · save state
Every substantive turn writes back to the Obsidian project README + emits canonical output frontmatter. Nothing important lives only in a session.
obsidian-vault write · canonical output emit · dispatch-activity.md
The 4 rails · apply at every layer
Guardrails
Permissions, sandbox limits, financial-read-only, session approval window, no-third-party-cloud, no proxies to route subscription lanes.
Doctrine
Hard-rule memories that fire in every session — load-state-first, save-state-last, silent-fallbacks-are-incidents, project lifecycle.
Observability
Per-job logs, routing_index, task-router logs, telemetry per scheduled job. Thin today — the next investment.
Cost · Subscription
Which billing lane is this? Max subscription vs Anthropic API vs local Ollama. Tracked so we can see spend per class per day.
The Three Modes

Every input plays one of three roles.

Rohit's diagram collapses everything into "Context." Atlas separates them because each has different ownership, different maintenance, and different failure modes.

Mode 01
Descriptive
"what is true, what's the state"
Canonical outputs · Obsidian READMEs · live BQ reads · Klaviyo live state · Xero cash position. Fails when state loading is skipped — the Klaviyo Path A incident.
Mode 02
Evaluative
"is this worthy, does this meet the bar"
taste-gate · destination-gate · brand references · identity anchors · Pinterest board analyses. Fails when work ships without the check — why taste-gate exists.
Mode 03
Prescriptive
"how to act, how to think"
Hard-rule memories · project lifecycle rules · writing & thinking doctrine · session-start-checklist. Fails when doctrine isn't loaded — why the memory file has priority.

Rebuild History

Four rebuilds. Each one a failure that named a layer.

Every architecture below is a result of a broken assumption in the one before it. The stack that survives is the one earned by failures.

01
Prompt-and-hope
Ask Claude, paste result somewhere. No memory. Every session started cold. Broke on: zero continuity — same mistakes on repeat.
2024 → early 2025
02
Skills + Rules (OpenClaw v1)
First real system — playbooks, skills, rules in a Git repo. But knowledge lived in tool state. Switch tools → start over. Broke on: tool lock-in.
mid 2025
03
vince-agents repo + MCPs
One Git repo. Every runtime reads from it. Custom MCP servers expose it. Portability solved. But state wasn't loaded — sessions re-invented instead. Broke on: the Klaviyo Path A incident.
late 2025 → mid 2026
04
Obsidian-first · doctrine-as-code
Obsidian as the persistent knowledge layer, per project. Hard-rule memory forces load-state before acting. Runtime bridged to Axis. LibreChat trialled + torn down. Where we are: can't repeat Path A.
2026-07 → live
